Car `eow` (brand-neutral "Electric OW"), GEN4-inspired. Research: `docs/research/cars/electric-ow.md` (values marked ASSUMED are tuning targets). Tracks (Mexico short layout, street circuits) and the time-based race (45 min + 1 lap) are later tasks (track-data skill; career race format).

Survey facts (2026-10-18): drive torque only on rear wheels (`vehicleModel.ts` ~L580-660, `diffSplit` per axle); `parseCarSpec` accepts `drive: 'rwd'` only; `brakeTorques(brakes, pedal, bias, out)` front share = bias; existing F1-style ERS (`src/physics/ers.ts`, `hudErs.ts`) with `overtake` input; voices defined by `CarSpec.sound.synth` (`soundSpec.ts`, `engineVoice.ts`), single `whine` layer, order ≤ 100; AI power from `carLimitsFromSpec` (torque-curve max).

## 281 contract

```ts
export interface MotorSpec { maxPowerW: number; maxTorqueNm: number; maxRpm: number; ratio: number; regenMaxW: number }
export function motorWheelTorque(m: MotorSpec, wheelOmega: number, powerCapW: number, throttle: number): number;
export function splitPower(capW: number, front: MotorSpec, rear: MotorSpec): [number, number];
export function regenSplit(axleBrakeNm: number, wheelOmega: number, m: MotorSpec, batteryFull: boolean): { regenNm: number; frictionNm: number };
export class Battery { constructor(capacityJ: number, startJ?: number); readonly capacityJ: number; get socJ(): number; get frac(): number; get empty(): boolean; get full(): boolean; drain(mechW: number, dt: number, eff: number): void; charge(mechW: number, dt: number, eff: number): void }
export const REGEN_MIN_OMEGA = 3; // rad/s
```
Rules: motor ω = |wheelOmega|·ratio; motor torque = throttle·min(maxTorqueNm, min(maxPowerW, capW)/ω_motor) (ω_motor 0 → maxTorque); 0 at ω_motor ≥ maxRpm·2π/60; wheel torque = motor torque·ratio. throttle clamped [0,1]. splitPower: proportional to maxPowerW, each ≤ its maxPowerW. regenSplit: limit = regenMaxW/|ω|; regen = min(request, limit); 0 if full or |ω| < REGEN_MIN_OMEGA; friction = request − regen. Battery clamps to [0, capacity]; startJ default = capacity.

Rear motor R = {350e3, 557, 20000, 7.8, 350e3}, front F = {250e3, 400, 20000, 7.8, 350e3}.
