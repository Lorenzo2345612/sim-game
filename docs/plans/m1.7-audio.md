# M1.7 — Audio: per-car engine synthesis and effects (2026-10-13)

Today `src/audio/engineAudio.ts` (task 051) is two oscillators + lowpass: sounds like a buzzer. Design: physically inspired synthesis (combustion pulse train per cylinder + exhaust resonance + intake noise) in an AudioWorklet, parameters per car in its JSON. No recordings needed. Runs after M1.5/M1.6 (cars have engine data, audio is wired by 054).

| # | Title | Deps | Cx |

| 108 | Engine synth DSP core (pure, Node-testable) | — | complex |
| 109 | Engine AudioWorklet and EngineAudio integration | 107, 108, 054, 070 | complex, heavy |
| 110 | Effects: shift cut, crackle on lift, wind, kerb rumble, gravel, tyre squeal | 109 | complex |

Contracts:
- 107: `CarSpec.sound?: { cylinders: number; exhaustLengthM: number; intakeMix: number; crackle: number }`; defaults when absent: 4, 1.2, 0.3, 0.2. Data: f4 4/1.0/0.35/0.1; gt3-a 8/1.4/0.25/0.5; gt3-b 6/1.1/0.3/0.4; gt3-c 8/1.5/0.2/0.6 (and any car added before it lands: V8 → 8/1.4/0.25/0.5).
- 108: `firingHz(rpm, cylinders) = rpm/60 · cylinders/2`; `class EngineSynth { constructor(p: { cylinders; exhaustLengthM; intakeMix; sampleRate }, seed: number); render(out: Float32Array, rpm: number, throttle: number): void }`. Model: per firing event an exponentially decaying burst (τ = 0.25 / firingHz), amplitude (0.2 + 0.8·throttle)·(1 ± 0.1 seeded per-cylinder jitter); feedback comb filter delay 2·L/343 s, feedback 0.5; intake = one-pole low-passed white noise (800 Hz) × intakeMix × throttle; tanh soft clip; rpm/throttle ramp linearly across each block from the previous block's values. Seeded mulberry32, no `Math.random`.
- 109: worklet processor wraps EngineSynth; EngineAudio keeps its public API; fallback to the old oscillators if `AudioWorklet` is unavailable; `__SIMGAME__.audioStats()` → `{ running: boolean; engine: 'worklet' | 'oscillator'; firingHz: number }`.
- 110: pure helpers `crackleSchedule(prevThrottle, throttle, rpm, limiterRpm, crackle, rng): number[]` (burst offsets in s), `windGain(speed)`, `kerbRumbleHz(speed, stripeMeters)`, `shiftEnvelope(t)`, plus wiring.
- 111: settings `volume.master|engine|effects` (0..1, default 0.8/1/1), cockpit camera adds a 1200 Hz lowpass on engine, pause mutes (ramp 0.1 s).
