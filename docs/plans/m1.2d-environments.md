## 157
`tools/env/bakeCity.ts <id>` (npm `build:env`): Overpass extract saved under `assets/source/osm/<id>-city.json` (ODbL row), baked to `public/tracks/<id>-env.json`: `{ buildings: { ring: [x, z][]; height: number; material: 'glass' | 'concrete' | 'brick' | 'stone' }[]; walls: { line: [x, z][]; height: number; thickness: number }[]; water: [x, z][][] }` in the track's local frame (same origin/projection as the track JSON). Range: within 600 m of the centerline; buildings intersecting the corridor (distance to centerline < half + max barrier offset + 5 m) dropped. Height: `height` tag (metres, strip units) → `building:levels` × 3.2 → type default (house 7, residential/apartments 15, commercial/retail/office 24, hotel 40, else 12). Material: height ≥ 40 → glass; historic or within an `historic=*`/old-city area → stone; residential/house → brick; else concrete. Old-city walls: `barrier=wall`/`historic=citywalls` ways inside the old-city area → walls height 8, thickness 2.5. Water: natural=water/basin polygons; coastline ways closed against the extract bbox on the water side. No `name`/brand tags in the output (only the fields above). Deterministic.

|---|---|---|---|
| AT1 | unit heightOf({height: '45 m'}) / ({'building:levels': '10'}) / ({building: 'house'}) / ({building: 'yes'}) | call | 45 / 32 / 7 / 12 |
| AT2 | bake baku | output | ≥ 800 buildings; every building's ring ≥ (half + max barrier offset + 5) m from the centerline; every height > 0; ≥ 1 wall line; ≥ 1 water polygon |
| AT3 | bake singapore / lasvegas | output | ≥ 600 buildings each; singapore ≥ 1 water polygon; some building ≥ 150 m tall |
| AT4 | any output file | search keys and string values | no key `name`, no string value other than the material enum |
| AT5 | bake baku twice | output | byte-identical |

## 158
