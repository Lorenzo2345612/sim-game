## 140–141 Paved run-offs, chicane escape roads, foam block barriers (2026-10-13)

User: Monza T1-style asphalt run-offs and escape roads, foam block (TecPro-type) barriers. Research: `docs/research/runoff-barriers.md` (OSM has none of these; gravel stays from OSM). Brand-neutral name in code: `foam`.

| # | Title | Deps | Cx |
|---|---|---|---|
| 140 | Builder: paved run-offs at heavy-braking corners, chicane escape roads, foam barrier placement | 098, 142 | complex |
| 141 | Render and colliders for escape roads and foam block barriers | 140, 103 | complex |

140 rules (tools/track-builder, deterministic; corner runs from `detectCorners`):
- Estimated speeds: vc = min(85, sqrt(1.6·9.81·Rmin)) m/s; approach = min(85, sqrt(vc² + 2·12·Lstraight)) with Lstraight = distance from the previous corner run's end to this run's start; drop_kmh = 3.6·(approach − vc).
- Heavy corner: drop ≥ 70 and Rmin < 120 → outside paved `runoff` of width clamp(10 + 0.1·drop, 10, 30) rounded to 0.5 m, spanning [start − 25, end + 10]; it replaces any gravel run-off on that side overlapping the span; barrier type over [start − 15, end + 10] on that side becomes `foam`.
- Medium: 40 ≤ drop < 70 (or 120 ≤ Rmin < 150 with drop ≥ 70) and outside barrier offset < 20 m → barrier type `foam` over [start − 15, end + 10]; run-offs unchanged.
- Chicane: two consecutive corner runs turning opposite ways, each Rmin < 80, gap between them < 120 m → escape road: polyline A → K → B, A = centerline point 10 samples before run 1, K = point on the approach tangent at A, at the along-track distance of B's projection, B = centerline point at the end of run 2; points every 2 m; width 8. `TrackDataV2.escapeRoads?: { points: [number, number][]; width: number }[]` (parser default []), `BarrierSegment.type` gains `'foam'`.

## 142–143 Kerbs on every corner, distance boards (2026-10-13)

User: kerbs on all corners, extending a few metres past the corner; distance-to-corner boards. 142 runs before 140 (140 gains dep 142; 140's AT5 compares against the post-142 JSON). 143 replaces M2.1b task 124 (boards are now static track data; 126 L3 reads them from the track JSON).

| # | Title | Deps | Cx |
|---|---|---|---|
| 142 | Kerbs on every corner with entry/exit extensions | 098 | complex |
| 143 | Distance-to-corner boards (builder data + rendering) | 140 | complex |

142 rule (`detectKerbs`, replaces the KERB_RADIUS rule): corner runs with Rmin < CORNER_RADIUS (400 m) and ≥ 4 points. Inside kerb [start − 15, end + 15]; outside exit kerb [end − 5, end + 20]; outside entry kerb [start − 20, start + 5] only when Rmin < 150. Same-side kerbs that overlap or touch are merged; output sorted by start; wrap indices. Sample spacing ~2 m (index offsets above are indices).

143: per corner run (same speed estimate as 140: drop_kmh) boards at 150, 100 and 50 m before the run start when drop ≥ 40, plus 200 m when drop ≥ 120 (distance along the centerline; skipped if it falls inside the previous corner run). Side = outside of the corner; lateral offset = max(half + KERB_WIDTH + 2, min(outside barrier offset − 1, half + 6)). `TrackDataV2.boards?: { index: number; side: Side; offset: number; label: 50 | 100 | 150 | 200 }[]` (parser default []). Render: instanced boards 1.2 × 0.8 m on a 1.2 m post, white face with black numerals (one 4-cell canvas atlas), facing approaching cars.
