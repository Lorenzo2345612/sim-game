# M1.2c — Visual realism (2026-10-13)

User feedback on M1.2: "se ve muy infantil" (cone trees, flat colours, block crowd, gradient sky, plain tyre stacks). Research: `docs/research/realism-assets.md`. Assets are fetched by the planner side (asset-scout) into the paths below before coding; specs only consume them.

Asset paths (all with `ASSETS_LICENSES.md` rows):
- `public/hdri/<name>_2k.hdr`: kloofendal_48d_partly_cloudy_puresky (Monza), kloofendal_overcast_puresky (Spa, Silverstone)
- `public/textures/foliage/{leaf-oak,leaf-pine}/{color,normal,opacity}.jpg`, `public/textures/bark/{plane,pine}/{color,normal,roughness}.jpg`
- `public/textures/ground/<track>.jpg` (Sentinel-2 true colour crop, 2048², covering `terrain` bounds; attribution "Contains modified Copernicus Sentinel data 2025")
- `public/textures/rubber/`, `public/textures/fence/{color,opacity}.jpg`
- `assets/source/crowd/*.glb` (Quaternius CC0 characters)
