# Budapest (Hungaroring) - visual reference (city/area name only; no series/brand marks)

Images: 119 local files in `.ai/refs/budapest/` (git-ignored, untrusted, not for `assets/`). Mostly pre-2025 state (old pit building and old stands). Colours are eyeball estimates; coordinates approximate. Licenses read from the Commons file metadata (API); re-check the linked page before any redistribution. Sponsor/series boards in photos must NOT be reproduced; use plain colour blocks.

## Overall

| Item | Observation |
|---|---|
| Environment | Natural bowl/valley in Mogyorod (Pest County), ~20 km NE of Budapest; track winds across the valley floor and flanks, "~80% visible from any point"; lat/lon 47.5822, 19.2511 |
| Relief | Gentle but constant: T1 Piquet is a downhill-right at the end of the long straight; T2 long downhill left to the valley floor; T4 uphill blind-apex left; T6-9 chicane/esses climb a hillside with spectator slopes; T11-T14 return downhill-uphill on the north side; total ~35-40 m range |
| Vegetation | Dry-grass meadows, sparse isolated trees, tree lines/forest on the ridge behind the stands (deciduous, oak/acacia, medium green #5E7F3A), dusty sandy soil |
| Sky/weather | hot, usually clear sky (pale blue #8FB8DE), dust haze, summer sun |
| Asphalt | mid grey #4A4A4D, abrasive, light patches |
| Grass | straw/dry green #8A9A4A beside track; hill slopes dry yellow-green #A9A860 |
| Gravel/run-off | tan sand-gravel #C2AE80 at most corners; some asphalt run-offs |
| Run-off paint | green #2E7D4F / dark green #2B5E3C painted outer strips next to kerbs (empty-track photos); blue-green #3FA9A0 on some kerb outsides |
| Kerbs | red #C8312C / white flat-and-serrated; some orange raised sausage kerbs at apexes (T6/7); grey concrete inside kerbs at T2 |
| Barriers | armco (silver) on green-painted posts; tyre walls with blue/green wraps (T5 outside); chain-link catch-fence ~4 m on steel posts; low concrete wall inside main straight |

## Top 10 priorities

1. Dry, sandy yellow-green terrain in a bowl; avoid lush green.
2. Long, low white pit building with glazed top strip on the right.
3. Large main grandstand roof spanning the front straight (blue seats).
4. Red/white kerbs with green painted outer strip; blue pit-lane edge.
5. Tan gravel traps, silver armco, tall green-grey catch fences.
6. Hillside natural spectator slopes at T4-T6.
7. Tight T6-T9 chicane/esses with orange apex kerbs.
8. Long downhill T2, uphill T4 profile (35-40 m total).
9. Tyre walls with coloured wraps at outside of T1/T5.
10. Sparse isolated trees and a forested ridge behind the stands; hot clear sky.
