## Steps

1. `buildTrackData.ts`:
```ts
import type { TrackData } from '../../src/core/types';
export interface TrackSourceConfig { id: string; name: string; widthMeters: number; reverse: boolean }
export interface GeoJsonLineFeatureCollection {
  type: 'FeatureCollection';
  features: { properties: { length?: number }; geometry: { type: 'LineString'; coordinates: [number, number][] } }[];
}
export function buildTrackData(geojson: GeoJsonLineFeatureCollection, config: TrackSourceConfig): TrackData;
```
   1. No `features[0]`: throw `Error('buildTrackData: no features')`. `coords` = copy of `features[0].geometry.coordinates`; if last equals first (both components), drop it.
   2. If `config.reverse`: `coords = [coords[0], ...coords.slice(1).reverse()]`.
   3. `origin = bboxCenter(coords)`; `pts = projectLonLat(coords, origin)`.
   4. `smooth = catmullRomClosed(pts, 20, 0.5)`; `res = resampleClosed(smooth, 2.0)`.
   5. Round every x and z of `res` to 2 decimals (`Math.round(v * 100) / 100`).
   6. `lengthMeters = Math.round(polylineLength(res, true) * 10) / 10`.
   7. `officialLengthMeters = properties.length ?? lengthMeters`.
   8. `N = res.length`; `sectors = [0, Math.round(N / 3), Math.round(2 * N / 3)]`.
   9. `source = { dataset: 'bacinger/f1-circuits', license: 'MIT', url: 'https://github.com/bacinger/f1-circuits' }`.
   10. Return `{ id, name, widthMeters, lengthMeters, officialLengthMeters, centerline: res, sectors, source }`.

2. `buildTrack.ts` (CLI; paths relative to repo root = cwd of `npm run`): internal constant
```ts
const TRACKS = [{ id: 'monza', name: 'Monza', widthMeters: 12, reverse: false, file: 'assets/source/tracks/it-1922.geojson' }];
```
   For each track: read the geojson with `node:fs` (`readFileSync` + `JSON.parse`), call `buildTrackData`, `dev = Math.abs(length - official) / official`; if `dev > 0.01`: `console.error(...)` and `process.exitCode = 1`. `mkdirSync('public/tracks', { recursive: true })`, write `public/tracks/<id>.json` with `JSON.stringify(data)` (no indentation). Print one line: `monza: N points, L m (official O m, deviation X%)` with X = `(dev*100).toFixed(2)`.

3. `tests/fixtures/square.geojson`: `FeatureCollection` with one closed `LineString` at the equator: `[[0,0],[0.01,0],[0.01,0.01],[0,0.01],[0,0]]`, `properties: { "length": 4448 }`.

4. Run `npm run build:tracks` and leave `public/tracks/monza.json` generated.

## Acceptance criteria

Tests in `tests/unit/track/buildTrackData.test.ts` (real geojson read with `node:fs`, plus the fixture):

- [ ] `monza has correct id and name`: `id === 'monza'`, `name === 'Monza'`, `widthMeters === 12`.
- [ ] `monza centerline has between 2800 and 3000 points`.
- [ ] `monza length is within 1% of 5793`: `lengthMeters` in [5735, 5851]; `officialLengthMeters === 5793`.
- [ ] `monza sectors are increasing and start at 0`: `sectors[0] === 0 < sectors[1] < sectors[2] < centerline.length`.
- [ ] `monza centerline last point differs from the first`.
- [ ] `monza coordinates are rounded to 2 decimals`: first 10 points, `Math.abs(v*100 - Math.round(v*100)) < 1e-6`.
- [ ] `square fixture builds without throwing` (`reverse:false`, `widthMeters: 12`); `lengthMeters` within ±2% of 4448.
- [ ] `reverse flips the winding`: signed area (shoelace over `[x,z]`) of the centerline has opposite signs for `reverse:false` and `reverse:true`.
- [ ] `npm run build:tracks` exits 0 and `public/tracks/monza.json` exists.
