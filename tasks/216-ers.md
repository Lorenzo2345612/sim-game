## Goal

A pure `Ers` class that models the MGU-K deploy/harvest energy flow per fixed step.

## Context

Pure physics: imports nothing from `three`; no allocation in `step`. Types from `./hybridTypes` (task 215): `HybridSpec`, `ErsMode`. SI units (W, J, m/s). Tests use the shared constants: mgukW 350000, batteryJ 4e6, deployJPerLap 8.5e6, harvestJPerLap 8.5e6, overtakeExtraJ 5e5, minSpeedMs 50/3.6, taperStartMs 290/3.6, taperEndMs 345/3.6, overtakeTaperStartMs 337/3.6, overtakeTaperEndMs 355/3.6, regenW 350000, superClipW 350000, liftHarvestW 100000; dt = 1/120.

## Steps

1. Export from `src/physics/ers.ts`:
```ts
export const ERS_MODE_FACTORS: Record<ErsMode, { deploy: number; clip: number }> = { charge: { deploy: 0.5, clip: 1 }, balance: { deploy: 0.8, clip: 0.5 }, attack: { deploy: 1, clip: 0 } };
export interface ErsInput { speedMs: number; throttle: number; brake: number; overtake: boolean }
export class Ers {
  socJ: number; lapDeployJ: number; lapHarvestJ: number; mode: ErsMode; overtakeUsedThisLap: boolean;
  powerW: number; clipping: boolean; overtakeActive: boolean;   // results of the last step
  constructor(spec: HybridSpec);          // socJ = batteryJ, counters 0, mode 'balance'
  get socFrac(): number; get deployCapJ(): number;
  step(inp: ErsInput, dt: number): number; // returns powerW (+ deploy to the drivetrain, - harvest)
  newLap(): void;   // lapDeployJ = lapHarvestJ = 0, overtakeUsedThisLap = false; soc kept
  reset(): void;    // socJ = batteryJ, counters 0, overtake flags false; mode kept
  setMode(m: ErsMode): void; cycleMode(): void; // charge -> balance -> attack -> charge
}
```
2. `step` rules, in order; taper(v,a,b) = clamp((b-v)/(b-a), 0, 1):
   1. powerW = 0, clipping = false, overtakeActive = false. If dt <= 0, speedMs < minSpeedMs or any input non-finite → return 0, nothing else changes.
   2. ot = overtake && socJ > 0. If ot: overtakeActive = overtakeUsedThisLap = true. deployCapJ = deployJPerLap + (overtakeUsedThisLap ? overtakeExtraJ : 0).
   3. brake >= 0.05 → harvest H = regenW * min(1, 2*brake). Else throttle < 0.05 → H = liftHarvestW. Else deploy: P = mgukW * taper(v, ot ? overtake taper : normal taper) * throttle * (ot ? 1 : deploy factor); if mode is charge, not ot and v >= taperStartMs → P = 0. P = min(P, socJ/dt, max(0, deployCapJ - lapDeployJ)/dt). If P > 0 → powerW = P. Else if throttle >= 0.95 and not ot → H = superClipW * clip factor (super-clipping).
   4. If no deploy: H = min(H, (batteryJ - socJ)/dt, max(0, harvestJPerLap - lapHarvestJ)/dt); powerW = -H; clipping = H > 0 and the super-clip branch was taken.
   5. socJ -= powerW*dt; lapDeployJ += max(powerW,0)*dt; lapHarvestJ += max(-powerW,0)*dt. 0 <= socJ <= batteryJ always.

Conventions: no rounding; thresholds as written (`<`, `>=`); invalid input returns 0 without mutation; `spec` is not mutated.
