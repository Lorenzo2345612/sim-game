## Steps

```ts
export type SectorColour = 'purple' | 'yellow' | 'none';
export interface HudV2Data {
  speedKmh: number; gear: number; rpm: number;
  lap: number; currentLapTime: number | null; lastLapTime: number | null; bestLapTime: number | null;
  sectorTimes: (number | null)[];     // length 3, this lap
  bestSectorTimes: (number | null)[]; // length 3, best per sector so far
  deltaSeconds: number | null;        // vs best lap, negative = faster
  lapValid: boolean;
}
export const SHIFT_LIGHT_RPM = 8200;
export const HUD_MAX_RPM = 9000;
export function sectorColour(time: number | null, best: number | null): SectorColour;
export class HudV2 { constructor(container: HTMLElement); update(data: HudV2Data): void; dispose(): void }
```

- Gear element text is the gear number. RPM bar `style.width` = `rpm / HUD_MAX_RPM × 100 %` clamped 0..100; element gets class `shift` when `rpm >= SHIFT_LIGHT_RPM`.
- `sectorColour`: `none` if `time` is null; `purple` if `best` is null or `time <= best` (first or faster than the best sector); else `yellow`. No green. Cell classes `sector-purple|sector-yellow`.
- Delta text: `-0.512` / `+0.300` (3 decimals, sign always shown); class `delta-neg` (green) when negative, `delta-pos` (red) otherwise; empty when null.
- INVALID badge: element with text `INVALID`, `display: none` when `lapValid`. Skip DOM writes when the text did not change (like `Hud`).
