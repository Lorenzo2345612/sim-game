## Goal

The game renders the F4 single-seater (from `assets/vendor/f4/f4_tatuus_t014_chasis.glb`, CC-BY 4.0) with spinning/steering wheels, the physics uses its real dimensions, and every Kenney asset is gone.

## Context

Source GLB facts (verified by the planner): Sketchfab export, 326k triangles, 43 meshes, 4 flat materials, no textures. Materials: `Cubo_008` (whole body), `neumaticos` (tyres), `GrisFreno` (brake discs), `GrisMordaza` (calipers). The nose already points to −Z, Y is up. Model units are not metres: uniform scale **1.47** gives a real F4 (length ≈ 4.29 m, width ≈ 1.74 m, wheelbase ≈ 2.72 m). Tyres are 2 meshes, one per axle, each containing both left and right tyres (nodes `neumatico_` = front, `neumatico__001` = rear); brake discs likewise (`disco_de_freno` front, `disco_de_freno_001` rear). Calipers stay on the body. Never use the word "Tatuus" in game files or output (the GLB `asset.extras` contains it). Add devDependencies (exact versions): `@gltf-transform/core@4.5.1`, `@gltf-transform/functions@4.5.1`, `meshoptimizer@1.3.0`.

## Steps

1. `buildF4.ts` reads the source GLB with `NodeIO` and writes `public/models/f4.glb` with exactly these top-level nodes: `body`, `wheel-front-left`, `wheel-front-right`, `wheel-back-left`, `wheel-back-right` (names from `WHEEL_NODE_NAMES`).
2. Transform: scale 1.47; then translate so the origin is on the ground (min tyre y = 0) below the midpoint between the front and rear axle centres, x centred. Left = −x, front = −z.
3. Wheels: split each axle's tyre mesh and disc mesh by vertex x sign into left/right; each wheel node's translation = its hub centre (centre of the tyre's bounding box) and its geometry is relative to that pivot.
4. Body: all other meshes merged per material into node `body`. Materials renamed `livery` (from `Cubo_008`, default base colour #c8102e), `tyre`, `disc`, `caliper`.
5. Optimise with `@gltf-transform/functions` (`weld`, `simplify` with `meshoptimizer`, `dedup`, `prune`) to ≤ 80 000 triangles total, keeping tyres round (≥ 24 segments). Strip `asset.extras` and any string containing "Tatuus".
6. Write `public/models/f4.json`: `{ wheelRadius, wheelbase, trackFront, trackRear, wheels: [{name, x, y, z}] }` in metres (hub centres in the GLB frame).
7. `F4_CAR.wheelRadius = wheelRadius`; `F4_CAR.wheelPositions[i] = { x, y: 0, z }` of the hubs in order FL, FR, RL, RR (the physics origin is the hub height; the renderer gets `bodyOffsetY = −(suspensionRestLength + wheelRadius)` so the model's ground meets the tyre contact at rest).

Conventions: 1 cm tolerance for derived dimensions; the pipeline is deterministic (same input, byte-identical output).
