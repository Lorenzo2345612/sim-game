# 016 — Create the speed and lap-time HUD

Status: pending
Phase: 0

## Goal

A top-left DOM panel shows speed, lap and times (current, last, best), with tested time formatting.

## Context

`ui` layer: receives the injected container `HTMLElement`. Speed already arrives in km/h (the `m/s * 3.6` conversion is done by the caller). The CSS is imported by `main.ts` (task 018), not by this task. Only `formatLapTime` is tested with Vitest (no DOM).

## Files

- `src/ui/formatTime.ts` — create
- `src/ui/hud.ts` — create
- `src/ui/hud.css` — create
- `tests/unit/ui/formatTime.test.ts` — create

## Steps

1. `formatTime.ts`: `export function formatLapTime(seconds: number | null): string`.
   - `null`, non-finite or `< 0` → `"-:--.---"`.
   - Otherwise: `totalMs = Math.round(seconds * 1000)`; `m = Math.floor(totalMs / 60000)`; `s = Math.floor((totalMs % 60000) / 1000)`; `ms = totalMs % 1000`. Result `` `${m}:${pad2(s)}.${pad3(ms)}` ``.
2. `hud.ts`:

```ts
export interface HudData { speedKmh: number; lap: number; currentLapTime: number | null; lastLapTime: number | null; bestLapTime: number | null }
export class Hud { constructor(container: HTMLElement); update(data: HudData): void; dispose(): void }
```

   - Constructor: use `container.ownerDocument` to create ONCE a `div.hud-panel` with 5 child rows (`div`): `.hud-speed` (no label), `.hud-lap` (no label), and three rows with a fixed label in a `span.hud-label` ("Current", "Last", "Best") followed by a `span.hud-value`. Append the panel to the container.
   - `update(data)`: compute the texts and write `textContent` only if it differs from the last stored string for that node:
     - speed: `` `${Math.round(data.speedKmh)} km/h` `` (if non-finite, 0), e.g. "123 km/h".
     - lap: `data.lap <= 0` → `"Lap -"`, otherwise `` `Lap ${data.lap}` ``.
     - current/last/best: `formatLapTime(...)`.
   - `dispose()`: removes the panel from the DOM (`panel.remove()`).
3. `hud.css`: `.hud-panel` { position: absolute; top: 12px; left: 12px; font-family: monospace; background: rgba(0,0,0,0.55); color: #fff; padding: 8px 12px; border-radius: 6px; }, `.hud-speed` { font-size: 28px; }, `.hud-label` { display: inline-block; width: 4.5em; opacity: 0.7; }. (The `#hud` container is already `position: fixed`.)

## Tests (`tests/unit/ui/formatTime.test.ts`)

- `formats 83.456 as 1:23.456`
- `formats 5.0 as 0:05.000`
- `rounds 59.9996 to 1:00.000`
- `formats 0 as 0:00.000`
- `returns placeholder for null` → `"-:--.---"`
- `returns placeholder for negative` (-1), `NaN` and `Infinity`.

## Acceptance criteria

- [ ] The tests pass; typecheck and lint without errors.
- [ ] `hud.ts` does not use the global `document` or `window`; it uses `container.ownerDocument`.
- [ ] A second `update` with the same data does not write `textContent` (comparison with the last string).
