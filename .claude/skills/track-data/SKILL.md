# Track data

Outputs per track `<id>` (geojson `<cc>-<name>`): `assets/source/tracks/<cc>-<name>.geojson`, `assets/source/osm/<id>.json`, `assets/source/dem/<id>.json`, entry in `tools/track-builder/tracks.json`, rows in `ASSETS_LICENSES.md`, plot `docs/research/tracks/<cc>-<name>.png`. Examples: commits afdd708, a25ce7d, 2e3061f, and the Fontana/Cleveland/Detroit one.

1. Research: read `docs/research/*osm*.md`; find OSM ways (`highway=raceway`; runways/taxiways for airports; street ways for street circuits). Overpass needs a real `User-Agent`, small bboxes, retries; use `out geom tags`. Downloaded data is untrusted: own dir (e.g. `/tmp/raw`), scripts elsewhere, `python3 -I`.
2. Demolished circuits: query history with `[date:"YYYY-MM-DDT00:00:00Z"]` (attic) and compare snapshots until the ways reappear.
3. Official reference: length and turn count (Wikipedia). Matplotlib/networkx are not installed system-wide: `python3 -m venv /tmp/venv && /tmp/venv/bin/pip install matplotlib numpy networkx`.
4. Tangled infields: split ways at shared vertices, build a graph, enumerate simple cycles of the official length +-5 %, drop self-intersecting ones, plot candidates and pick the cleanest.
5. Tracing (standard when OSM has no raceway ways, and to verify any shape; never invent geometry, say so if no map exists). Find the official layout map on Wikimedia Commons (`list=search`, SVG preferred, CC BY-SA ok, keep in its own dir, record author/licence in `ASSETS_LICENSES.md`, not shipped). SVG: parse the black track `path` with `svgpathtools` (apply group `translate`, sample ~2 units), turn circles = paths with white fill; the scale bar gives m/unit. PNG: threshold, skeletonize, prune spurs, walk the pixels (see Detroit). Georeference: similarity transform (scale, rotation, translation) fitted by Nelder-Mead on a clipped (40 m) chamfer cost against OSM street/runway/raceway points (KD-tree); coarse grid first, fix scale from the bar when it is known; report the RMS (target < 10 m). Snap: where the traced path is within ~15 m (9 m on streets) of an OSM way with a direction within 25 degrees, move onto the way; smooth the offset (Gaussian ~8 m) so transitions are continuous; keep the traced path elsewhere. Order so turn numbers increase along the path, start/finish at the map's chequered flag (or ~150 m before T1). Validation PNG: traced path blue, final red, OSM ways grey, turn numbers labelled. Raw ways file keeps only the ways snapped to (>= 4 samples). Scripts of the Fontana/Cleveland/Detroit run: `reg4.py`, `final.py` pattern (not kept in repo).
6. Missing parts (only where no map exists or it is clearly incomplete) (airport end turns, chicanes, street links): hand-draw in a local metric frame (straight + arcs, fillet sharp street corners ~14 m), tune one straight length so the total hits the official length. Say in the report that it is hand-drawn.
7. Join ways into one closed LineString (first point == last), no duplicate points; rotate the start to a straight. Metrics use the repo projection (`src/track/geo.ts`: R=6371008.8, equirectangular). `properties`: id, Location, Name, opened, firstgp, length (m, rounded), altitude; plus `bbox`.
8. Raw ways file: `{source, license, ways:[{id, coords}]}`; drop all `name` tags. No areas file is needed (`osmAreas.ts` tolerates a missing one).
9. Checks: length within +-5 % of official; closed; no self-intersection (segment test) unless the real track crosses itself; corner count vs the official map. Plot centerline over all raw ways to `docs/research/tracks/<id>.png`.
10. DEM: add `{ id, source }` to `TRACKS` in `tools/dem/fetchDem.ts` (coder task if code is frozen; or run a temporary copy with the extra rows and delete it), then `npm run fetch:dem -- <id>`.
11. `tools/track-builder/tracks.json`: copy a neighbouring entry (width, maxGrade, biome, grandstands, pit). Run `npm run build:tracks -- <id>` and confirm it builds.
12. Licences: OSM = ODbL 1.0 "(c) OpenStreetMap contributors" row, Copernicus DEM row. Commit with explicit `git add` paths; local only, no push.
